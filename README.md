# Disassembler

Скрипт на python, который преобразует Hex-код в асcемблерский код

##Технологии
* **Язык**: Python 3.13+
* **Библиотека:** Встроенный модуль string (сторонние зависимости отсутствуют) 

##Возможности
- **Широкая база инструкций:** Распознаёт 124 команды
- **Надёжность:** Автоматически проверяет контрольную сумму
- **Униферсальность:** Работает даже с отрицательными числами
- **Точность:** Выдаёт команды с учётом частных случаев
