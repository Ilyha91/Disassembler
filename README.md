# Disassembler

Скрипт на python, который преобразует Hex-код в асcемблерский код

##Технологии
* **Язык**: Python 3.13+
* **Библиотека:** Встроенный модуль string (сторонние зависимости отсутствуют) 

##Возможности
- **Широкая база инструкций:** Распознаёт 124 команды
- **Надёжность:** Автоматически проверяет контрольную сумму
- **Униферсальность:** Работает даже с отрицательными числами
- **Точность:** Выдаёт команды с учётом частных случаев

##Структура проекта
-Для корректной работы проекта необходимо установить файлы: commands.txt, commanders.txt, minus_cmds.txt

##Как запустить проект
1. Скачайте весь репозиторий
2. Откройте терминал или командную строку в папке с распакованными файлами
3. 3апустите скрипт командой:
   python disassembler.py
